# Session 11 – WiFi, HTTP GET & POST with ESP32

## Overview

In this session, we learned how to connect an ESP32 to WiFi and send/receive data over the internet using HTTP requests.

The project combines:

* ESP32 WiFi connection
* HTTP GET request
* HTTP POST request
* JSON data format
* ArduinoJson library
* FreeRTOS tasks
* Sensor data sending

---

## What I Learned

### WiFi Connection

The ESP32 connects to a WiFi network using:

```cpp
WiFi.begin(WIFI_SSID, WIFI_PASS);
```

Before sending HTTP requests, the code checks:

```cpp
WiFi.status() == WL_CONNECTED
```

---

### HTTP Protocol

HTTP is used for communication between a client and a server.

In this project:

* The ESP32 is the client
* The server receives or sends data
* The ESP32 sends requests and reads responses

---

### GET Request

A GET request is used to receive data from a server.

Example endpoint:

```text
http://api.open-meteo.com/v1/forecast?latitude=32&longitude=34&current_weather=true
```

The response is returned in JSON format.

---

### POST Request

A POST request is used to send data to a server.

Example endpoint:

```text
http://httpbin.org/post
```

The ESP32 sends sensor data as JSON.

Example JSON:

```json
{
  "reading_id": 1,
  "temperature": 25.1,
  "humidity": 60.2,
  "distance": 30.5,
  "device": "RoboGreeno-ESP32"
}
```

## FreeRTOS Tasks

### sensorTask

Reads sensor values every 2 seconds.

Updates:

```cpp
g_temp
g_hum
g_distance
```

---

### wifiTask

Sends sensor data to the server every 5 seconds using HTTP POST.

Stack size:

```cpp
8192
```

---

### displayTask

Prints:

* Temperature
* Humidity
* Distance
* WiFi status
* POST status

to the Serial Monitor.

---

### bleTask

Sends the latest sensor data using BLE notifications.

## Important Notes

### Wokwi WiFi

```cpp
const char* WIFI_SSID = "Wokwi-GUEST";
const char* WIFI_PASS = "";
```

For a real ESP32 board, use your actual WiFi credentials.

---

### Check WiFi Before HTTP

```cpp
if (WiFi.status() == WL_CONNECTED)
```

---

### Always Free Resources

```cpp
http.end();
```

---

### JSON Header

```cpp
http.addHeader("Content-Type", "application/json");
```

## Common Problems

### WiFi Stuck on Connecting

Possible causes:

* Wrong SSID
* Wrong password
* Using Wokwi credentials on real hardware
* Arduino Cloud credentials mismatch

---

### ArduinoJson Error

```text
ArduinoJson.h: No such file or directory
```

Install ArduinoJson from Library Manager.

---

### HTTPClient Error

Correct:

```cpp
#include <HTTPClient.h>

HTTPClient http;
```

Wrong:

```cpp
HttpClient http;
```

---

### Arduino Cloud Conflicts

Avoid using names already defined in thingProperties.h:

```cpp
SSID
PASS
temp
hum
distance
```

Use:

```cpp
WIFI_SSID
WIFI_PASS
g_temp
g_hum
g_distance
```
