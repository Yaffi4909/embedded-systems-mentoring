# Embedded Systems Mentoring

This repository contains hands-on exercises, assignments, and projects completed during an Embedded Systems mentoring program. The projects cover a wide range of embedded development topics, including microcontrollers, sensors, communication protocols, RTOS concepts, cloud connectivity, and wireless communication.

## Repository Structure

### Sessions

| Folder                                                                               | Description                                                               |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| [session-02-traffic-light-system](./session-02-traffic-light-system)                 | Implementation of a basic traffic light control system.                   |
| [session-03-colorfull-led-control](./session-03-colorfull-led-control)               | RGB LED control and color management exercises.                           |
| [session-04-smart-robot-monitor](./session-04-smart-robot-monitor)                   | Smart robot monitoring project with sensor integration.                   |
| [session-05-freertos-queue-button-led](./session-05-freertos-queue-button-led)       | Introduction to FreeRTOS using tasks, queues, buttons, and LEDs.          |
| [session-06-uart-communication](./session-06-uart-communication)                     | UART communication exercises between embedded devices.                    |
| [session-08-dht22-freertos](./session-08-dht22-freertos)                             | Reading temperature and humidity data from a DHT22 sensor using FreeRTOS. |
| [session-09-arduino-coude-sensor-and-led](./session-09-arduino-coude-sensor-and-led) | Integration of sensors and LEDs with Arduino Cloud.                       |
| [session-10-add-ble-to-sensor](./session-10-add-ble-to-sensor)                       | Adding Bluetooth Low Energy (BLE) capabilities to a sensor-based system.  |
| [session-11-add-wifi-to-the-system](./session-11-add-wifi-to-the-system)             | Adding Wi-Fi connectivity and network communication features.             |
